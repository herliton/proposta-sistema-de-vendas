# Proposta — Sistema de Vendas Automotivas

Aplicação front-end em React + Vite desenvolvida para demonstrar um painel de gestão comercial de concessionária, com foco em propostas, clientes, veículos, equipe e relatórios financeiros.

## Visão geral

A plataforma simula um sistema de operação comercial para uma loja de veículos, permitindo:

- acessar um dashboard executivo com indicadores de vendas;
- acompanhar simulações e propostas em andamento;
- gerenciar clientes e históricos de atendimento;
- controlar estoque de veículos e valorização;
- acompanhar desempenho de vendedores e comissões;
- consultar relatórios de comissões e produção.

## Funcionalidades principais

- Tela de autenticação com fluxo demo de login
- Dashboard comercial com KPIs e gráficos
- Gestão de usuários e permissões
- Cadastro e consulta de veículos
- Gestão de clientes e histórico de relacionamento
- Painel de suporte e acompanhamento da equipe
- Relatórios e cálculos de comissões
- Fluxos interativos de simulação e proposta

## Stack

- React 19
- Vite 8
- TypeScript
- Tailwind CSS v4

## Como executar localmente

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

A aplicação ficará disponível em:

```text
http://localhost:4173/
```
