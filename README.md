# Proposta de Sistema de Vendas

Aplicação front-end em React + Vite para gestão comercial de vendas, propostas, clientes, veículos e relatórios.

## Tecnologias

- React 19
- Vite 8
- TypeScript
- Tailwind CSS v4

## Como rodar localmente

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

A aplicação estará disponível em:

```text
http://localhost:4173/
```

## Build de produção

```bash
npm run build
```

## Observações

- Projeto preparado para desenvolvimento local.
- O ambiente Figma Make foi usado como base para a interface.
- Em seguida, o repositório pode ser enviado para o GitHub.
